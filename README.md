# 喵星计划 / Cat Planet

南塘猫屋共创官方网站（CP 计划）。

## 这是怎么来的

去年在南塘村生活时，遇到一只猫，叫**呦唬**。后来它陆陆续续生下了 **7 只小猫**。
从去年 10 月到今年 5 月，店里一直在做繁育孵化，猫越来越多。

现在即将入冬。10 月上旬，几所高中的校长号召大家一起买猫粮；戴姐觉得，
可以带着孩子们一起来。于是这件事就串起来了：趁 11 月 16–18 日秋假，
带孩子们一起做一个猫屋。

## 这是什么

2026 年 11 月 15–18 日，秋假期间带孩子一起打造猫屋，轻量快闪测试。

- **11/15 建设场景**：孩子＋创新老师＋木工师傅＋猫进场
- **11/16–18 快闪 P.B.L**：项目式学习
- 约 15 个孩子、3–4 个亲子家庭；不收费、食宿自理；来不来都可以
- 经费：第四期费用一部分＋第三期剩余；材料费不多（主要丙烯）；接受猫粮、猫砂捐助

定位：先跑通脉络再看结果。「轻量」不是目标，是手段——目标是跑通南塘「线上商量＋线下动手」的共创脉络。

最重要的一点：带孩子一起实践**生命关怀与照护**。

这有点像「石头汤」：每个人带一点东西来，一起煮出一锅汤。我们没有非常具象的目标，
也没有强计划性的做法——先把局攒起来，细节大家一起来定。

## 网站

本站是 CP 计划的官方网站，第一版是一个活动页：点进来像一张活动海报邀请，往下展看到时间、参与方式、猫屋共创过程。

- 技术：TypeScript + Vite 静态站，部署在 Cloudflare Pages（推送到 main 分支自动部署）
- 不用 GitHub Pages
- 网址：https://cat-planet-of-nantang.pages.dev

## 怎么参与

这份宣传主要面向成年人——先打通家长这一层，把活动宣传出去。

1. **家长**：带孩子来参与
2. **过往的共创伙伴**：现场参与，也可以捐款捐物，共同筹谋推进
3. **记录**：整个过程做好记录，这本身就是一个很有意思的过程
